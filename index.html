Selected research & projects

Learning, perception and robot systems

01

Mobile manipulation & imitation learning

Ongoing · KTH engineering project

A simulation and demonstration-processing pipeline for the Rainbow Robotics RBY1, developed within the MoBiPi mobile-manipulation project. Current work includes door-closing demonstrations and Diffusion Policy training and evaluation.

RBY1MuJoCoMimicGenDiffusion Policy
Technical contributions
  • Work with robosuite, RoboCasa and robomimic to prepare demonstrations and evaluate manipulation policies.
  • Debug controller metadata and action representations; validate an action adapter across 100 saved simulator states, including contact configurations.
  • Investigate trajectory replay and policy rollout behavior using RGB and end-effector observations.
02

Visual room transitions & topological memory

Ongoing

RGB-based room-transition detection and visual memory for scene representations that do not require a globally consistent metric map. The work combines temporal visual features, simulated trajectories and indoor robot recordings.

RADIOTemporal CNNsHabitat-Sim / HM3DSpot / Odin data
Technical contributions
  • Develop temporal convolutional models over RADIO visual embeddings and evaluate missed transitions and repeated detection peaks.
  • Build trajectory collection in Habitat-Sim for HM3D environments.
  • Develop candidate-room matching and room-level visual memory toward a topological scene representation.
03

Autonomous aerial recovery & landing

Research Engineer · KTH ALARS

Perception development for aerial recovery of underwater robots and work on a DJI Matrice 350 autonomous-landing pipeline. The system connects visual detections, relative-state estimation, landing logic and control.

ROS 2YOLO OBBEKFLQR
Technical contributions
  • Calibrate a 360-degree camera and train object detectors with real and synthetic imagery.
  • Work on EKF relative-state estimation, landing state-machine integration and LQR control.
  • Develop and debug simulated trajectory tracking and landing behavior, including temporary loss of visual detections.
