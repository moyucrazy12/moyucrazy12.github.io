# CristhianMC Portfolio

Personal portfolio showcasing robotics projects, research, experience, and awards.

**Preview:** open `index.html` or run `python3 -m http.server 8000`.

- `index.html` — text and sections
- `content.js` — images, videos, and links
- `styles.css` — appearance
- `script.js` — tabs and preview controls
- `images_videos/`, `assets/media/`, `pdf_files/` — original media, optimized previews, and documents
